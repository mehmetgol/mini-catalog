# Mini Catalog

A simple product catalog mobile application built with Flutter and Dart.

## Features

* Product listing using JSON data
* Search products by name or category
* Filter products by category
* Product detail page
* Add products to shopping cart
* Remove products from shopping cart
* Display total cart price
* Material 3 user interface

## Technologies

* Flutter
* Dart
* JSON
* Material Design 3

## Project Structure

```text
mini_catalog/
├── assets/
│   └── products.json
├── lib/
│   ├── main.dart
│   └── product_detail_page.dart
├── pubspec.yaml
└── README.md
```

## Getting Started

Make sure Flutter is installed.

Clone the repository, then run:

```bash
flutter pub get
flutter run
```

## Data Source

Product information is loaded from a local JSON file: `assets/products.json`.

## Purpose

This project was developed as a beginner Flutter application to practice widgets, navigation, JSON parsing, search, filtering, and state management.
